## Signup mechanics (both roles)
- Stepper: Account type → (Investor type) → Your details (first/last/work email/country/address) → **Send OTP** → "Check your email — 6-digit code" (6 boxes; email subject "Your Aika Africa Fund Registration verification OTP", arrives < 10 s) → "Verify & create account" → "Create your password … Activate account" → straight into the role dashboard (no admin approval gate to *enter*; approval gates *features*).
- Investor "Your details" has NO address field and country is a free-text input; Founder has a country select + business address.
- Role determines the dashboard root: `/dashboard/companies` (Founder) vs `/dashboard/fund-manager` (Investor). Login has no role selector.

## Founder / SME dashboard (`/dashboard/companies`)
- Sidebar groups: GET STARTED (Company Profile, Agreements & Declarations, Documents, Notifications) · MY COMPANY (Dashboard, Investor Connections, Service Providers, Investment Rounds, Milestones, Team, Verification Status, My Classification) · REPORTING (Due Diligence, KPI Tracker, Financial Analysis) · ACCOUNT (Audit Trail, Settings). Top pill tabs Overview/Profile/Financials/Documents/Verification.
- Dashboard = **Onboarding Progress** stepper (Account Created → Company Profile → Documents Uploaded → Identity Verified → Business Verified → Classification, "17% complete", "30 days left") + 4 task cards (Complete profile / Upload documents [locked until profile] / Identity & Business verification / Await classification) + Recent Activity.
- **Agreements & Declarations**: "Legal Compliance Checkpoint" — 3 documents (NDA, Statutory Declaration, PlatformTerms), each "Review & Sign" → modal with rendered agreement (letterhead, dated, Aika COO signature pre-applied) + **Your Signature: Draw / Initials / Upload image** → "Sign & Submit" ("By signing, you confirm you are an authorised representative"). Progress ring "x / 3 signed"; signed docs show "Signed · View / Re-sign". Uploads are locked until NDA + Statutory Declaration are signed.
- **Documents**: requirement matrix "0/47 required" with category tabs (Business 37 / Identification 1 / Financial 9), per-document cards (Required / Multiple / accepted types / max 20 MB), file table with Status + Quality columns. Locked until profile complete + agreements signed.
- **Investor Connections**: statuses Interested → Review Pending → Paired → Completed / Declined / Withdrawn / Dissolved; "Your marketplace listing will attract investors once approved."
- **Investment Rounds**: KPIs (Active rounds / Investor interests / Active connections / Completed); "Create Investment Round" modal: Title, Grant type (Equity/SAFE/Convertible Note/Debt), Round type (Seed/Series A/B/Bridge/Other), Target amount, Minimum investment, Closing date, Description.
- **Team**: "Add Team Member" (first, last, email, platform role: Admin / Finance Manager / Legal Counsel / Operations Manager / Member / Viewer) — "They'll get an email to accept and set up their account".
- Milestones ("plan appears once your platform manager has set it up"), Verification Status (auto checks; "Pending Manual Review"/"Re-upload Required"), My Classification (scoring engine), Due Diligence (documents 0/99, financial analysis, verification checks), KPI Tracker, Financial Analysis, Audit Trail (event/entity/IP/time), Settings (email+SMS notification toggles, language, timezone, Close account).

## Investor / Fund Manager dashboard (`/dashboard/fund-manager`)
- Sidebar: MARKETPLACE (Investment Opportunities) · MY FUND (Fund Dashboard, Portfolio, Deal Pipeline, Investment Profile, Team Members) · PERFORMANCE (Fund Performance, LP Management, Distributions) · COMPLIANCE (Fund Documents, Agreements, Verifications) · ACCOUNT (Notifications).
- **Marketplace gate** ("Finish setting up your account"): 1 Complete profile (investment preferences incl. sectors) → 2 Sign the agreements (NDA + Platform Terms) → 3 Upload documents. Each step flips to "Done"; marketplace unlocks only when all three are done. (Observed: signatures reverted once after uploads — re-signing restored them.)
- **Investment Profile**: Fund Details (name, type, life, target IRR, status, investor type) · About · Contact · **Investment Mandate** (mandate text, currencies, risk appetite, reporting currency, min/max ticket, portfolio value, total investments) · **Investment Preferences** (industries chips, stages chips, regions/countries chips, contact method, tags, Accredited / Impact / Mentorship / Advisory / Public profile yes-no) · Online presence · Limited Partners.
- **Fund Documents**: Phase 1 Minimum Baseline (8 items, 4 required*) → Phase 2 fund-manager documents; statuses Not uploaded / Under review / Needs update; "Replace".
- **Marketplace** (after unlock): tabs **Fund Evaluations** (my connections; statuses Awaiting Response / Under Review / Accepted / Not Accepted / Withdrawn / Relationship Active / Ended) and **Browse Listings** (counters Listings/Sectors/Countries; filters sector / stage / country; teaser cards: name, status Active, tagline, sector, stage, country, founded, team size, "View Profile").
- **Listing profile**: header (name, sector · country, stage) + **"Add to Pipeline"** (= express interest) + tabs Overview / Investment Rounds; Company overview (country, HQ, founded, team size), Impact & SDG, Existing investors, Profile & activity (Document completeness %, "1 active interest", Listed date). No financials on the teaser.
- **Deal Pipeline** (the fund's own kanban): Screening → Due Diligence → Term Sheet → IC Review → Closed / Passed; Table|Kanban toggle; "Add New Deal" modal (company, sector, country, ask USD, stage, assigned to, entry date, expected close, instrument, use of funds).
- **Team Members**: "Invite Team Member" (first, last, email, role Member/…) — "We'll email an invitation. Once they accept, they'll set their own password."
- Fund Performance (IRR/MOIC/DPI/TVPI, capital deployment, distributions), LP Management, Distributions, Verifications (KYC/KYB records), Notifications.
